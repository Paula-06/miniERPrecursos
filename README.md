## Frontend

El frontend de la aplicación se encarga de la interfaz de usuario y de la interacción con la API REST del backend.

### Tecnologías
- HTML5
- CSS3
- JavaScript (fetch API)
- Sin frameworks externos

###                    Estructura del Frontend 

### Ubicación
El frontend está servido desde Tomcat en la ruta:

El frontend se encuentra dentro del proyecto backend, en la ruta:

backend/webapp/ui/

Archivos principales:
- `index.html` → estructura de la interfaz
- `styles.css` → estilos visuales
- `app.js` → lógica de la aplicación y llamadas a la API


### Funcionalidades
- Pantalla de login
- Dashboard con estadísticas
- Gestión de empleados
- Gestión de activos
- Gestión de asignaciones

### Interfaz

La interfaz permite:

- Iniciar sesión
- Navegar entre las distintas vistas
- Visualizar datos del sistema
- Gestionar empleados, activos y asignaciones
- Mostrar estadísticas en un dashboard
